# Volleyball Stat Tracker

A WPF desktop application for managing volleyball player statistics with local JSON storage.
Features

  1. CRUD Operations: Add, view, edit, and delete players (Name, Age, Minutes, Points, Club).
  2. JSON Persistence: Automatically saves and loads player data (players.json).
  3. Dynamic UI: Auto-hides empty list views and handles contextual form modes (Add/Update).
  4. Input Validation: Prevents crashes using safe numerical parsing (int.TryParse).
