# Volleyball Stat Tracker

A WPF desktop application for managing volleyball player statistics with local JSON storage.
Features

    CRUD Operations: Add, view, edit, and delete players (Name, Age, Minutes, Points, Club).

    JSON Persistence: Automatically saves and loads player data (players.json).

    Dynamic UI: Auto-hides empty list views and handles contextual form modes (Add/Update).

    Input Validation: Prevents crashes using safe numerical parsing (int.TryParse).
